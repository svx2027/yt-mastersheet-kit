# yt-mastersheet-kit

> 🚧 Landing Aug 7-13 as part of a public tooling rollout (Aug-Sep 2026).

Config-driven YouTube channel tracker built on yt-dlp (no API key, no quota): a non-technical operator edits one YAML config and gets verified, paste-ready master-sheet blocks plus a QA note.

Roadmap: see the profile README at [github.com/svx2027](https://github.com/svx2027).
